description: Triggered when diagnosing errors, unexpected behavior, or failed runs
---

## Before starting
1. Read vault/known-issues/ — this may already be documented
2. Read CONTEXT.md — check current known broken items
3. Read the specific module in AGENTS.md that is failing

## Debugging approach
1. Reproduce the error with minimum steps
2. Identify the module responsible
3. Check vault/known-issues/ for prior workarounds
4. Fix and verify

## After fixing
• Update vault/known-issues/ — remove resolved issue or add new one
• Update CONTEXT.md status if applicable
