# PE Team Project Template

**LG Electronics — TN Production Engineering Team**

## How to use this template

1. Clone or copy this repo into your new project folder
2. Open the project in Windsurf
3. Open `.windsurf/workflows/bootstrap.md`
4. Paste the bootstrap prompt into the Windsurf AI panel
5. Let the AI read the codebase and fill all vault files
6. Review `vault/` contents for accuracy
7. Run your first commit using `.windsurf/workflows/commit.md`

## Structure

• `CONTEXT.md`       — current project status, always up to date  
• `AGENTS.md`        — architecture and module map  
• `vault/`           — institutional memory (config, decisions, hardware, issues)  
• `.windsurf/rules/` — coding and workflow conventions  
• `.windsurf/skills/`— auto-loaded context by task type  
• `.windsurf/workflows/` — session, commit, audit, and bootstrap procedures
